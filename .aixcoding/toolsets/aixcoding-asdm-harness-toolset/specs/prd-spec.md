# PRD 文档规范

## 概述

此规范定义 PRD（产品需求文档）的结构模板，供 `asdm-harness-design` action 生成 PRD 时参照。模板分为固定骨架和 Agent 自由扩展区两部分。

## 文档命名

```text
FT-{id}-{name}-PRD.md
```

存放路径：`.asdm/workspace/asdm-harness/feat/FT-{id}-{name}/`

## 固定骨架

## Agent 自由扩展区

除上述固定骨架外，Agent 应根据特性复杂度和 Code Research 结果**自行决定是否添加**以下章节：

| 可选章节 | 适用场景 |
| ---------- | ---------- |
| 领域设计 / 技术方案 | 需深入描述核心领域逻辑（流程、状态机、数据同步等） |
| 系统架构 | 特性涉及跨模块架构变更 |
| 数据模型 | 特性涉及数据库 schema 变更或新表设计 |
| 接口设计 | 特性涉及新增或修改 API |
| 依赖关系 | 特性依赖其他特性或外部服务 |
| 风险与缓解 | 存在技术风险或不确定性 |
| 相关文档 | 需关联其他特性的文档 |

**编写规则**：

- 可选章节的标题、子节结构、内容格式均由 Agent 自行决定
- 章节顺序按逻辑合理性排列（位于「使用场景」之后、「验收条件」之前）
- 目录必须与实际生成的章节保持一致
- 如特性足够简单，可以不添加任何可选章节

## 内容规范

| 禁止 | 替代方案 |
| ------ | ---------- |
| JSON 请求/响应示例 | 使用表格描述字段结构 |
| SQL 建表语句 | 使用表格描述表结构 |
| Java/TypeScript 代码块 | 使用文字描述功能 |
| 表格格式目录 | 使用可点击的缩进列表格式 |

| :----: | ------ |
| ✅ | 已实现 |
| 🟡 | 部分实现 |
| ❌ | 未实现 |
| 🔲 | 待新增 |
