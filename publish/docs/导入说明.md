## 🎯 验证步骤

### 1. 导入测试数据
1. 打开页面 publish/index.html
2. 点击 "📌 已订阅 (0) → 弹窗出现
3. 点击 "📥 批量导入" → 选择文件 → 选 my-subscribed-services.txt
4. 点击 "✅ 确认导入" → 应提示"成功导入 30 个服务"

> ✅ 注释行（#开头）和空行应被自动过滤，不会导入

### 2. 查询并对比
1. 组件编号输入 E00301，点击 "🔍 查 询"
2. 点击 "🔄 对比订阅"
3. 观察结果：
   - 前 10 条中应该有 **10 个显示 "✓ 已订阅"**（绿色徽章）
   - 第 11 条开始显示 **"✗ 未订阅"**（琥珀色高亮 + [订阅]按钮）
4. 顶部统计卡片应显示：已订阅 10 / 未订阅 N / 订阅率 X%

### 3. 快速订阅测试
- 点击任意未订阅服务的 [订阅] 按钮
- 该行应立即变为 "✓ 已订阅"，高亮消失
- 统计数字实时更新

## 🔧 生成你自己的测试数据

手动从接口获取：
```bash
curl -s -X POST http://localhost:3000/getPublishDataList \
  -H "Content-Type: application/json" \
  -H "token: YOUR_TOKEN" \
  -d '{"compNum":"E00301","pageNum":1,"pageSize":20}' | python3 -c "
import json, sys
for r in json.load(sys.stdin)['data']['rows'][:20]:
    print(r['serverCoding'])
" > my-subscribed-services.txt
```
