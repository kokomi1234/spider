## 🎯 验证步骤

### 1. 导入测试数据

1. 打开 `http://localhost:3000/index.html`（先启动代理，见 `publish/README.md`）
2. 点顶部「📌 已订阅」按钮 → 弹出订阅管理面板
3. 点「📥 批量导入」→ 选择 `publish/tools/my-subscribed-services.txt`
4. 点「✅ 确认导入」→ 应提示导入成功

> `#` 开头的注释行与空行会被自动过滤，不会导入。

### 2. 查询并对比

1. 筛选「提供方系统」选 E00301 → 点「🔍 查 询」
2. 点「🔄 对比订阅」
3. 结果：
   - 命中列表里的服务显示 **「✓ 已订阅」**（绿色徽章）
   - 未命中的显示 **「✗ 未订阅」**（琥珀色高亮 + [订阅] 按钮）
   - 顶部统计卡片显示：已订阅 N / 未订阅 N / 订阅率

### 3. 快速订阅

点任意未订阅服务的 [订阅] 按钮 → 该行立即变「✓ 已订阅」，统计数字实时更新。

## 🔧 生成你自己的测试数据

最省事的办法是**从抓包导入**，而不是手工复制编码：

```bash
cd publish
node tools/har-import.js ../analysis/har/查询接口.har   # 真实响应灌进 cache/
PROXY_OFFLINE=1 node proxy.js                            # 离线回放，页面照常查询
```

然后查询一次并点「⬇ 导出 CSV」，取「服务编码」列存成 `.txt` 即可。

> 早先文档里的 `curl` 写法已不再适用：接口路径必须是完整后端路径
> （如 `/itamp-tool/publish/getPublishDataList`）、`token` 也只有 12 小时有效，用抓包更可靠。
