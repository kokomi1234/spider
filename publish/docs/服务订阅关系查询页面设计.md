## 一、页面概述

**用途**: 查询和管理服务订阅关系数据，支持多维度筛选、结果展示、查看和导出。

**技术栈**: 原生 HTML/CSS/JS，无框架无构建。复用现有 `bfe-design` 风格组件库（`searchable-select`、`date-picker`、主题变量等）。

**文件位置**: `publish/subscription.html` + `publish/js/page/subscription.js`

## 八、技术实现要点

### 8.1 UI 组件复用

- **可搜索下拉**: `createSearchableSelect()` — 所有 `<select>` 类型的筛选条件
- **日期选择器**: 本页面不需要日期选择
- **主题变量**: 间距 `--sp*`、字号 `--fs-*`、圆角 `--r-*`、颜色令牌全部走 `theme.css`
- **按钮样式**: `filled btn-sm`（主按钮）、`outlined btn-sm`（普通按钮）

### 8.2 查询条件联动

- **提供方系统 ↔ 调用方系统**: 共用同一数据源 `window.loadProviderList()`，但作为独立筛选维度
- **提供方变更批次 ↔ 调用方投产批次**: 共用同一数据源 `window.loadBatchList()`，独立筛选
- **提供方部门 ↔ 调用方部门**: 共用同一数据源 `window.loadDepartmentList()`，独立筛选

### 8.3 多选下拉处理

- `sysServeNoList`、`serverCodingList`、`prodSysServeNoList` 为数组类型
- 使用 `createSearchableSelect()` 的多选模式（通过 `multiple: true` 选项控制）
- 选中值以 tag 形式展示在输入框上方
- 提交时将选中值转为数组放入请求体

### 8.4 表格性能

- 使用 `table-layout: fixed` + `colgroup` 预定义列宽
- 表头 `position: sticky; top: 0` 吸顶
- 固定列使用 `position: sticky; right: 0` / `left: 0`
- 最大高度 500px，内部滚动

### 8.5 导出功能

- 后端返回文件流（`application/octet-stream` 或 `application/vnd.ms-excel`）
- 前端创建 `<a>` 元素触发下载
- 导出按钮基于当前所有查询条件（包括分页前的全部数据）

### 8.6 请求管理

- 所有请求走 `window.API.call()`，统一注入 token、处理 CORS
- 查询时使用 `AbortController` 取消旧请求
- 失败返回 `{ok:false, error}` 不抛异常，UI 层展示错误提示
