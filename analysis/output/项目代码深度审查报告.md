## 自动化清理脚本（可选，默认只报告，不删除）

以下脚本只扫描项目内明确的备份/缓存候选，默认 dry-run；只有传入 `--confirm` 才会把**备份文件和 `.DS_Store`**移入系统废纸篓。它不会删除 HAR、`.env`、cache 或任何不确定文件。

```python
#!/usr/bin/env python3
from pathlib import Path
import argparse
import subprocess

ROOT = Path(__file__).resolve().parent
CANDIDATES = [
    ROOT / "publish/tools/legacy/date-picker-old.js",
    ROOT / "publish/tools/legacy/date-picker.js.backup2",
    ROOT / "publish/tools/legacy/searchable-select.js.bak",
    ROOT / "publish/tools/legacy/test-batch.html",
    ROOT / "publish/.DS_Store",
    ROOT / ".DS_Store",
]

parser = argparse.ArgumentParser()
parser.add_argument("--confirm", action="store_true", help="确认后移入 macOS 废纸篓")
args = parser.parse_args()

found = [p for p in CANDIDATES if p.is_file()]
for p in found:
    print(f"候选: {p}")

if not args.confirm:
    print("仅扫描，没有任何文件被删除。请人工确认后再执行 --confirm。")
    raise SystemExit(0)

for p in found:
    subprocess.run(["osascript", "-e", f'tell application "Finder" to delete POSIX file "{p}"'], check=True)
    print(f"已移入废纸篓: {p}")
```

> 建议先处理高风险资产隔离与令牌轮换，再处理备份文件；本次审查没有执行清理。
