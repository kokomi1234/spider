# 任务单查询 - 接口文档

> 来源：`任务单查询.har`
> 基础域名：`https://itamp.bocsys.cn`

## 认证方式

所有接口均通过自定义 Header 进行身份认证，无需额外登录：

| Header | 说明 |
|--------|------|
| `token` | 用户令牌 |
| `ssopSessionId` | SSO 会话 ID |
| `systemId` | 系统标识（itamp） |
| `appId` | 应用标识（projectManger） |
| `outsiderUserToken` | 外部用户令牌 |

**注意：** 服务器使用内部 CA 签发的 SSL 证书，调用时需跳过证书验证（curl 加 `-k`，requests 设 `verify=False`）。

## 通用请求头

| Header | 值 |
|--------|-----|
| `Content-Type` | `application/json`（POST）/ 默认（GET） |
| `Accept` | `application/json, text/plain, */*` |
| `appId` | `projectManger` |
| `systemId` | `itamp` |
| `authMethods` | `udp` |

## 通用响应格式

- **成功：** HTTP 200，body 包含 `code: 200`、`msg: "操作成功"`
- **失败：** HTTP 200，body 包含错误码和错误信息
